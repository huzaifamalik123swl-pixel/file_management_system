# 📁 File Management System

A simple File Management System built using Python and Bash scripting.  
This project allows users to manage files efficiently through command-line operations.

---

## 🚀 Features

- 📂 Create files
- 🗑️ Delete files
- 📖 Read file content
- ✏️ Update files
- 📝 Maintain logs of operations
- 🔧 Backend automation using Bash script

---

## 🛠️ Technologies Used

- Python 3
- Bash (Shell Scripting)
- Linux Command Line

---

## 📁 Project Structure
file_management_system/
